# Supabase Auth email templates

Generated by `node scripts/emails/build.mjs` from one shared layout. Edit the script, not
the HTML files, then rebuild.

To install: Supabase dashboard → **Authentication → Emails → Templates**. For each row,
open the template, set the subject, paste the whole HTML file into the body, and save.

| Dashboard template | Subject | File |
|---|---|---|
| Confirm sign up | `Confirm your Kitloom account` | `confirm-signup.html` |
| Invite user | `You are invited to Kitloom` | `invite.html` |
| Magic link or OTP | `Your Kitloom sign-in link` | `magic-link.html` |
| Change email address | `Confirm your new email address` | `change-email.html` |
| Reset password | `Reset your Kitloom password` | `reset-password.html` |
| Reauthentication | `Your Kitloom verification code` | `reauthentication.html` |

The placeholders (`{{ .ConfirmationURL }}`, `{{ .Email }}`, `{{ .NewEmail }}`, `{{ .Token }}`,
`{{ .SiteURL }}`) are filled in by Supabase. `{{ .SiteURL }}` is the **Site URL** in
Authentication → URL Configuration.

Design: dark card on carbon, the lime "knot" wordmark, a lime thread rule, Purl with an
expression that fits the email, one lime action button, the link written out in case the
button does not render, and a safety note. Tables and inline styles only, no images, no web
fonts, so it renders in Gmail, Outlook and Apple Mail. Purl is pixel art made of table
cells, drawn from the site's sprite data, so no inbox blocks it. Clients that force a light
theme may invert colours; the content stays readable.
